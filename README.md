# Orbital 33 Icon Pack

Paquete de iconos 3D para Samsung Theme Park y launchers compatibles.

## Catálogo ampliado

- 117 asociaciones de aplicaciones en `appfilter.xml`.
- 1.500 diseños Orbital originales adicionales disponibles en el catálogo de selección manual.
- Esta tanda incorpora 57 esferas vectoriales personalizadas nuevas y actualiza la esfera de Roblox, con paletas y símbolos individuales inspirados en cada aplicación.
- La cobertura automática depende de los nombres de paquete y actividades launcher reales de cada versión instalada.

## Instalar y probar

1. Instala el APK publicado en GitHub Releases.
2. Abre Theme Park y selecciona Orbital 33.
3. Comprueba las aplicaciones mapeadas. Si alguna no cambia, comparte su versión para corregir su actividad launcher.

## Compilar

Requiere JDK 17, Android SDK y Gradle 8.9: `gradle assembleDebug`.

## Verificación

GitHub Actions valida XML, componentes únicos, recursos de cada icono y el catálogo de 1.500 diseños antes de compilar. La aplicación real debe verificarse en el dispositivo Samsung.
